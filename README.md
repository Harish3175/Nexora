# Nexora — Creative Design Agency

A modern, responsive design agency homepage built with Next.js and Tailwind CSS as part of a Next.js Developer Internship Task.

## Features

- Responsive design for desktop, tablet, and mobile
- Hero section with call-to-action
- Services section with four service cards
- Portfolio section with project thumbnails
- Portfolio image hover animations
- Contact form with basic validation
- Contact form success message
- Responsive mobile navigation
- SEO metadata
- Optimized images using Next.js Image
- Smooth scrolling navigation
- Hover and transition animations

## Tech Stack

- Next.js 16
- React
- JavaScript
- Tailwind CSS
- Next.js Image
- ESLint
